# Curated demonstration outputs

These files are generated by `python demo/run_demo.py` and intentionally tracked
so a reader can inspect one end-to-end model run without executing the code.

- `fire_progression.png`: selected three-dimensional history states.
- `air_temperature.png`: cell-air temperature histories.
- `item_energy.png`: remaining combustible energy in the ignition cell.
- `item_heat_output.png`: per-object heat output in the ignition cell.
- `summary.md` and `summary.json`: compact scenario settings and results.
- `agent_activity.csv`: tidy occupant positions by saved tick.
- `fire_department_activity.csv`: fire-service unit state and actions.

The outputs are synthetic and unvalidated. Regeneration replaces the files.
